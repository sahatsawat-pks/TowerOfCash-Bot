### 4. index.js - Command Handlers
Need to add hidden command handlers:

```javascript
// Command routing needed:
client.on('messageCreate', async (message) => {
    if (!message.content.startsWith('!')) return;
    
    const gameId = activeGames.get(message.channel.id);
    if (!gameId) return;
    
    const game = games.get(gameId);
    const player = game.players.find(p => p.user.id === message.author.id);
    
    // Check if player has the command
    if (!player.hiddenCommands.includes(commandType)) {
        return message.reply('You don\'t have that command!');
    }
    
    // Route commands:
    if (message.content === '!fold') {
        await game.executeFold(player);
    } else if (message.content === '!blammo') {
        await game.executeBlammo(player);
    } else if (message.content.startsWith('!shuffle ')) {
        const space = parseInt(message.content.split(' ')[1]);
        await game.executeShuffler(player, space);
    } else if (message.content === '!wager') {
        await game.executeWagerer(player);
    } else if (message.content.startsWith('!bonus ')) {
        const boostType = message.content.split(' ')[1];
        await game.executeBonusBag(player, boostType);
    } else if (message.content.startsWith('!truth ')) {
        const space = parseInt(message.content.split(' ')[1]);
        await game.executeEyeOfTruth(player, space);
    } else if (message.content === '!failsafe') {
        await game.executeFailsafe(player);
    } else if (message.content.startsWith('!minesweeper ')) {
        const space = parseInt(message.content.split(' ')[1]);
        await game.executeMinesweeper(player, space);
    } else if (message.content === '!repel') {
        await game.executeRepellent(player);
    }
    // Wildcard handled through special logic
});
```

## 📝 Technical Notes

### Bomb Weight System
- Total weight: 50 (matching RtaB Season 6)
- Normal bombs are most common (26/50 = 52%)
- Special bombs at 6% each (3/50)
- Rare bombs at 2% each (1/50)
- Event-generated bombs (weight 0) placed by specific events

### Command Weight System
- Total weight: 111
- Common commands: 99% (10 × 11 weight)
- Ultra-rare Wildcard: 1% (1 weight)
- Players can hold multiple commands
- Commands consumed on use (except Wildcard which mimics)

### Event Weight System
- Weights adjust based on player count
- Some events excluded in 2P/3P games
- Seasonal events (weight 0) activated by host
- Total active weight varies by game size
